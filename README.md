# *** право для любимого

Статическое веб-приложение для iPhone. Никаких аккаунтов и установки приложения на телефоны студентов не требуется.

## Что уже есть
- 50 билетов;
- по 3 вопроса на билет;
- 4 перемешиваемых варианта для вопросов с выбором;
- свободный ответ с ручной оценкой «Верно / Неверно»;
- показ правильного ответа;
- сохранение прогресса в localStorage;
- «Продолжить тест» и «Начать заново»;
- избранное;
- неправильно отвеченные;
- режим всех билетов и отдельного билета;
- интерфейс только на русском, крупный жирный чёрный текст, без фотографий и декоративных элементов.

## Как дать студентам одну ссылку
Самый простой вариант — загрузить папку на любой статический хостинг. Например, GitHub Pages, Cloudflare Pages или Netlify. После публикации студенту отправляется одна ссылка.

На iPhone:
1. открыть ссылку в Safari;
2. нажать «Поделиться»;
3. выбрать «На экран Домой»;
4. открыть значок с экрана — приложение будет выглядеть как отдельное окно.

Регистрация, база данных и установка из App Store студентам не нужны. Данные конкретного студента сохраняются только на его устройстве.

## Важно
База вопросов сформирована из загруженной теории. Перед использованием как официального экзаменационного тренажёра желательно вручную проверить формулировки и правильные ответы: автоматическая переработка текста не заменяет юридическую редактуру преподавателя.
